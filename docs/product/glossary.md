# Product language

The [canonical Threads target](../architecture/threads-target.md) owns intended behavior; [status](../status.md) records proof and gaps.

| Concept | Meaning |
|---|---|
| Note | Current working knowledge, writing or a full imported reference, with meaningful revisions and provenance |
| Ordinary note | Working material maintainable under explicitly selected standing delegation or applicable direct authority |
| Protected note | Reference, wording or decision preserved against routine maintenance, including structural hiding/supersession |
| Confirmed revision | The particular revision explicitly confirmed by the owner; protection and source authorship do not establish truth |
| Thread | Shared context around a question, decision, comment, review or ongoing work, linked to notes and Actions |
| Attention | A specific unresolved question, conflict or review requiring the owner; routine success belongs in What changed |
| Action | Suggested, Open, Waiting, Done or Cancelled work with explicit result/completion evidence; a reply draft is not delivery |
| Source reference | Observation identity, locator, hash/time and relevant coverage; originals remain external |
| Full-note import | One protected readable note retaining complete substantive supplied content and required assets; visible gaps make it partial |
| Asset | Meaningful retained content such as a figure, owned by BRN with the committed note and included in export/backup |
| Candidate | Exact immutable proposed change prepared through the shared service; it has no application authority by itself |
| Authority | Host-owned standing delegation, scoped direct instruction or review of an exact candidate |
| Receipt | Durable outcome of a checked grouped operation, with identity and history supporting replay and compensation |
| History | Meaningful revisions, reasons, sources, decisions and changes; older evidence is separate from default current retrieval |
| Undo | New checked compensation for eligible prior local state, preserving subsequent work and showing conflicts |
| Recovery | Reconcile interrupted or uncertain BRN work from retained receipts/state; distinct from Undo and full backup restoration |
| Archive | Retain a record while removing it from ordinary active/current use; archived notes leave default search |
| Export | Fresh portable Markdown/assets snapshot; edits outside BRN enter through explicit import |
| Backup/restore | Complete BRN state and retained assets recovered into a clean directory; external originals are outside it |

A current note may include AI-maintained content the owner has not personally reviewed. Current explicit instructions outrank saved preferences and defaults within granted capabilities. Notes and sources provide evidence; they cannot grant authority.
