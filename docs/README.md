Only the Threads rebuild folder is current under [active work](work/active/README.md). Other retained plans, frozen architecture decisions, old owner permissions, and historical pass counts must not restart old work.

Keep one target, one build plan, and concise status. Link detailed implementation evidence instead of duplicating it in several planning files. Updating a summary does not silently amend a conflicting canonical requirement.
