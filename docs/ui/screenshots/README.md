# UI screenshot index

Retain all safe BRN screenshots captured during UI work in a dated folder here,
using the original returned image bytes. Each folder's index identifies the
screen, source commit or working change, synthetic fixture and observation.
Screenshots support later UI improvements; they do not establish owner acceptance.
Exclude sign-in codes, tokens, credentials and private/original data. Record an
excluded capture in the test evidence without retaining its sensitive pixels.
