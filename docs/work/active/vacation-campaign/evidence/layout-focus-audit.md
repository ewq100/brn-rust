## Finding

No source-backed defect found in the requested close/hide/maximize/reopen/reorder/launcher-return transitions. `Layout` can intentionally reach an empty panel list (inline test `open_close_toggle_replace_areas_and_mark_custom`, `crates/brn-desktop/src/threads_layout.rs:587-612`), but this is not an unrecoverable empty workspace: closing a focused tile chooses the adjacent/first remaining tile or `None` (`:424-443`), while panel toggles and ordinary open commands route through the always-present shell and can repopulate it (`threads_shell.rs:1304-1317`; `threads_ui.rs:974-982`). The intentional minimum is therefore not “one panel must remain.”

Pure layout invariants are coherent for the audited transitions: `visible()` returns only the maximized tile or all tiles (`threads_layout.rs:285-299`); applying a non-solo preset repairs focus if that tile is absent (`:324-349`); open/open-beside focus their destination and retarget an existing solo maximize (`:351-409`); close repairs focused identity and unmaximizes a closed maximized tile (`:424-443`); maximize rejects absent/Settings destinations and sets focus to the valid tile (`:509-519`); focus cycling is bounded to visible tiles (`:520-534`). Swap/move change positions while preserving tile identity and focus (`:457-490`), so reorder does not make the focused kind hidden or absent.

Host transitions inspected use the common focus adapter after structural changes: `relayout` runs the change and then `focus_tile_contents` (`threads_ui.rs:987-997`); shell close/maximize/close-other-splits callbacks call it (`threads_shell.rs:116-170`, header buttons `:442-456`, layout menu `:1313-1317`); show-beside does likewise (`threads_shell.rs:818-829`). `focus_tile_contents` clears stale reveal intent and resolves focus through the current `layout.focus()` (`threads_shell.rs:1547-1589`): Note chooses a visible editor/read view, Chat its composer or archived Unarchive, Notes search, AllThreads filter, other focused panels their body, and `None` the root. A deferred first-control move checks the same body still owns focus before traversing (`threads_shell.rs:1622-1636`). Launcher open focuses its query; Escape and command selection close it through `close_launcher`, which returns focus via `focus_tile_contents` before command navigation (`threads_ui.rs:2512-2528`, `:2565-2578`).
