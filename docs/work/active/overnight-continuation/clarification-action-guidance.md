# Clarification drafts under unresolved execution authority

## Baseline, evidence and bounded outcome

Baseline predecessor candidate `df0cd6c`, stacked on merged P4 PR92. Cedar's
paired synthetic trial used exact identical retained Source/Current with no
approval between conditions. Luna read the applicable tail controls via search,
reported them accurately and honestly disclosed its truncated read. It submitted
zero drafts because the vendor lacked authorization to execute/reply. Sol used
the range tool, retained exact tail evidence and prepared a follow-up Action with
unknown owner, supplementary Knowledge and a tentative Finding.

Existing ACTIONS guidance, tool/schema and product contracts already permit
review drafts with nullable owners and separate exact approval. No contradictory
rule or backend defect was demonstrated. The observed abstention supports a small
generic clarification; it does not establish prompt causality or model superiority.

Outcome: make explicit that absence of execution authorization does not by itself
exclude a useful review draft to clarify a request, prepare a response or seek an
owner decision. Preserve the choice to abstain where no useful follow-up is
supported, and never imply assignment, acceptance, release, spending permission
or completion. Do not force an Action count or encode Cedar answers.

## Reuse, implementation and acceptance

Adapt only the existing shared ACTIONS behavior and affected real-Rig transport/
coherent-guidance tests and contracts. Reuse the nullable-owner schema, exact
proposal tools, authority guards, versioned review and approval; no new tool,
semantic policy engine, data format, dependency or runtime.

Qualify delivery on every existing provider route and keep captured old question/
answer replay unchanged. Relevant synthetic cases: an unanswered request with an
unknown owner; a restricted execution request supporting only clarification; and
informational material with no useful follow-up. Reviewable clarification keeps
owner null and uncertainty explicit; approval remains separate, no automatic
execution and no forced proposal. Deterministic tests prove instruction delivery
and contract mechanics, not stochastic model usefulness.

After independent complete-candidate review and applicable checks, a bounded
paired Medium follow-up may use two of the remaining eight shared investigations.
Use identical retained inputs within each pair; record existing Findings/context
or fresh fixture identities honestly when comparing to the earlier run. Each run
retains 180 seconds/eight tool rounds/nine responses, no retries/substitutions.
No inference is needed to inspect/edit/approve/replay any retained results.
All GUI observation stays in the single morning task.
