# X2 common document-backend implementation plan

**Goal:** make Xberg1.3.10 the common document-intake backend across every current BRN document kind, preserving exact plain-text behavior, typed source fidelity, dedicated Luna conversion and checked host save. PDF is the first engineering slice, not the entire adoption objective.
**Architecture:** one existing intake facade with a helper-only shared Xberg adapter and format-specific projections into schemas1/2. Markdown/Text retain an explicit verbatim identity mode, zero model calls and their existing provider/helper-independent availability; identity decoding is not an alternative document parser. No Xberg DTO leakage, second worker/protocol, new parser registry/framework or hidden fallback.
**Stack:** Rust1.98.1; exact xberg1.3.10/defaults-off with individually gated format features (pdf first; office/excel/email/html planned). Existing image/PNG/serde and Rig/Luna. Root lock and shared paths remain principal-owned.
**Spec:** [LATEST owner all-document scope](owner-scope-all-documents.md), [historical start approval](owner-decision.md), [master§8/A2–A5,§11,§17](../proposal/final/01-master-plan.md), [published X1 result](../experiments/x1-xberg.md), and the full [pinned DESIGN](https://github.com/ewq100/brn-rust/blob/65715ee538bfaffdd442307d2ffa631cbd2b68bc/experiments/x1-xberg/DESIGN.md).
