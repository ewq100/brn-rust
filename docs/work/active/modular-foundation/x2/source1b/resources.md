## Reachability and build/runtime separation

Chosen bytes+exact MIME path does not read source filenames/URIs; filename remains a bounded host label, never path authority. Use_cache=false, no injected cache, max archive/embedded recursion disabled, OCR/image OCR/model processors off. Engine generic remote/model APIs and email PST temp route compile but must not be selected. No HTTP/child executable is needed by the selected inspected pure document readers; this static observation is not a real no-file/no-network sandbox test. Build scripts and bundled source compilers are a separate graph, not runtime helper permissions.

Image union includes rayon/extra codecs, native PNG/JPEG paths and font code. Per-package archive/source treatment covers those exact reused X1 identities; no top3-only provenance shortcut. Additional features may expose new operations even without new packages, so shared graph/resource requalification precedes admission.

No extraction/RSS/latency/threads were measured. PDF's unresolved operations block PDF implementation; they do not block a separately allocated real Xberg HTML engineering slice after explicit admission/fidelity bounds. Plain/Markdown exact identity remains available throughout. No library-wide unqualified failure claim or silently weakened quality contract.
