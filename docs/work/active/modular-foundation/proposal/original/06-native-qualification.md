## Ordered walkthrough

1. Open/create the draft and write text. Switch documents and restart. Confirm draft recovery and no implicit data loss.
2. Attach an existing reference and import another through the native file picker. Check progress, fidelity/partial states, assets and correct project/private scope.
3. Add a brief and reference purposes. Open a new chat, switch chat and close Chat. Verify these remain available to document-level writing.
4. Select the second copy of an identical paragraph and add a comment. Repeat with Estonian diacritics, combining characters and emoji. Confirm exact highlighting/reveal.
5. Resize, wrap and scroll a long document. Reopen the comment after layout changes; test keyboard selection, clipboard and native IME/composition. Record any unperformed IME case explicitly.
6. Add several comments plus overall feedback and run a document-level rewrite with Chat closed. Confirm actual Sources used and a review candidate, not an automatic saved rewrite.
7. Ask for a paragraph change; then separately ask for a full requirements check against an oversized reference. Confirm honest relevant-passages versus full-reading/partial coverage.
8. Inspect before/after review and source passages. Confirm references were not modified, unsupported material is flagged and source content cannot trigger actions.
9. Generate another revision, then type a new edit before completion. Confirm typing is retained and stale Apply cannot overwrite it.
10. Change/remove a reference or revoke project access during a run. Confirm the result/source pane obeys current fencing and no inaccessible content leaks through cached previews.
11. Apply an exact reviewed revision; repeat the operation and use durable Undo. Then test local typing Undo and subsequent Save. Confirm no duplicate operation or stale text resurrection.
12. Stop import/rewrite at a late stage. Confirm no false success/late save. Restart and inspect retained work, queued requests, candidate identity and cleanup.
13. Exercise scoped search, source reading and Connections with a private distractor. Check visible counts and source previews. Exercise unavailable/partial embeddings and rebuild a disposable derived index.
14. Backup the synthetic workspace and restore to a separate fresh destination. Confirm references, brief, assets, drafts/revisions and history survive without the original binary source being retained in BRN.
15. Launch the minimal writing development host and run a representative real-service comment/rewrite/review/Undo flow. Confirm it does not need BRN's entire desktop shell.
16. Recheck ordinary chat, project navigation, queue/Stop, tasks and an existing authorized-maintenance fixture. Confirm writing modularization did not change their behavior.
