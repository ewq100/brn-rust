## Plan review

On 1 October 2026, at the user's request, a GPT-6.1 Sol (high reasoning) rubber-duck agent reviewed the plan read-only. It reported 8 findings (0 critical, 3 high, 5 medium); all were incorporated:

1. Native `-D warnings` gates failed in Tasks 1–4 (a compiler probe found 26 dead-code errors). Fixed with a temporary `#[allow(dead_code)]` that Task 5 Step 5 narrows. `Page` is now kept until Task 4 Step 9.
2. Open-rail dividers were not budgeted in `resolve`. Occupied width now includes the 5 pt divider. A boundary test was added, and Task 4 renders static separators.
3. Scroll positions were lost across collapse, Focus and tab switches, and drafts shared a scroll handle with sources. Each region now owns a `ScrollHandle`, with separate draft and source handles.
4. Post-hoc `Theme` field writes missed cached tokens, editor colours and the Base projection. Handoff colours are now installed as `ThemeConfig`s through `Theme::change`, generated by `tokens::theme_config_json`.
5. `.toggled` is accessibility-only. Visible selection now uses `Selectable::selected`.
6. Settings was not modal, and a global Escape binding consumed editor Escape. Settings now uses the toolkit `open_dialog` host, and the global Escape action was removed.
7. A late draft-open completion could override newer navigation. Added `DocNavigation` correlation, with a test.
8. A drag released outside the root was not persisted. Added `on_mouse_up_out` and ending the drag on window deactivation.

The reviewer confirmed the Task 1/2 arithmetic, module visibility and glob chains, the GPUI signatures and shortcut strings, and retention of the guards and capabilities. The revisions have not been compiled; Rust verification happens during execution.
