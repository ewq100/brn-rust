## Failures preserved and corrections checked

Earlier full-Markdown replies failed binding/list/escaping checks; their receipts are preserved. Early PDF attempts failed preparation time limits or typed-plan validation. Scan06 source inspection found incorrect heading depth, alphabetic continuation text instead of nested lists, and an Outlet label after the footer. The later plan fixes hierarchy/nesting. An initial global coordinate sort fixed Outlet but failed review because it could interleave multi-line prose columns; that rule was replaced.

The final parser preserves Poppler flow/block order for prose. It only joins isolated explicit one-line flow-and-block fragments with complete finite rectangles, an exactly coincident vertical interval and nonoverlapping horizontal bounds. Joined fragments appear in horizontal order at the earliest original group position. Multi-line groups, overlapping or unmatched fragments, absent grouping and incomplete geometry retain extraction order. This bounded rule repairs the isolated Outlet row without inferring columns or globally sorting a page.

The earlier research `layout.pdf` was inspected read-only (SHA-256 `7b5f3c6f129ac50c2e68646021f28f3f6a99f1f715391fb659a01960fc976fa1`). It visibly has two prose columns, but Poppler already emits those paragraphs interleaved as separate one-line flows. The parser cannot honestly reconstruct their authored column structure and leaves the extraction limitation visible; no new model conversion of that input was run.

For visually justified PDF reflow, the typed page plan may supply an optional complete permutation of zero-based nonempty source-line indices. Omission keeps source order. The checker requires every line exactly once, rejects missing/duplicate/out-of-range indices, and compares normalized visible Markdown with the unchanged source-line contents joined in that order. Altered identifiers or values fail that comparison. Empty scan pages cannot claim a source-line permutation. This permits explicit column reflow while retaining source content; it does not make an inferred layout or completeness claim. The accepted process-scan plan uses the default source order; the explicit-permutation path was covered by deterministic tests, with no additional provider call.
