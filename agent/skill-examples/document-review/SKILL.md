# Document review

This instruction-only example is guidance, not authority. Installation does not enable it. Use only tools actually available under current host scope and permissions. Do not fetch dependencies, change provider/settings, install packages, enable connectors or claim a protected-edit grant.

1. Confirm the owner's current review objective. Search permitted current notes and read exact saved versions; keep source claims distinct from accepted owner decisions.
2. Compare support and disagreements using the [review checklist](references/checklist.md). Identify missing evidence and unresolved questions without inventing commitments.
3. Report proposed next steps separately from actual applied operations. A suggested revision is a draft until checked preparation, exact review where required and an actual Applied receipt.
4. Preserve supplied references and originals. Do not rewrite a source or claim external delivery. Stop and current host authority always take precedence over these instructions.
